Primeira versão pública do **Lume**, uma biblioteca local de filmes, séries e animes para Windows.

### Escolha seu download

- **`Lume-0.1.0-windows-x64-setup.exe`**: instalador para a sua conta do Windows, com assistente em português e preparação do WebView2 quando necessário.
- **`Lume-0.1.0-windows-x64-portable.zip`**: extraia todo o ZIP em uma pasta gravável e abra `Lume.exe`. Catálogo, histórico e player preparado ficam na pasta `data`. O portátil requer WebView2 já instalado.
- **`SHA256SUMS.txt`**: hashes para conferir a integridade dos downloads.
- **`THIRD-PARTY-NOTICES.txt`**: avisos das dependências incluídas.

### Primeiro uso

O assistente ajuda a preparar o player e escolher as pastas da biblioteca. É possível baixar uma versão fixa do mpv diretamente da origem, com verificação SHA-256, ou selecionar um `mpv.exe` existente. Os pacotes públicos do Lume não redistribuem o binário do mpv. A preparação automática precisa de internet; depois disso, reprodução e catálogo funcionam offline.

### Incluído

- Catálogo com busca, filtros e visualização em grade/lista.
- Reconhecimento de temporadas e episódios; correção manual em lote.
- Player nativo com troca de áudio e legendas internas/externas.
- Histórico com retomada da posição, inclusive após fechar o aplicativo.
- Instalador e modo portátil com armazenamento separado.
- Código MIT e compilação de releases automatizada no GitHub Actions.

### Limites conhecidos

Esta é uma **pré-release** para Windows x64. As capas são ilustrações locais, sem metadados online. A leitura das pastas é atualizada manualmente. Arquivos movidos ainda não são reconciliados automaticamente com o histórico anterior. Não há assinatura de código do Windows nesta versão; o editor pode aparecer como desconhecido.

Para atualizar o portátil, substitua os arquivos do programa e **preserve a pasta `data`**. O ZIP não contém dados pessoais nem uma biblioteca de exemplo persistida.
